1. HOW DOCUMENTS WERE GENERATED:
- Generated synthetically via `backend/scripts/generate-golden-set.cjs`.
- Creates synthetic PDF byte streams using raw string concatenation with Helvetica Type1 font.
- Does NOT contain scanned-style images, noise, skew, compression artifacts, stamps, or handwriting.
- Contains the PDF stream syntax flaw `(Text) 0 -20 Td Tj` which violates standard PDF operand ordering and causes syntax errors in Poppler utilities.

2. DID REAL TESSERACT PROCESS SCANNED-STYLE IMAGES?

- Neither `backend/scripts/run-ai-evaluation.cjs` nor `backend/src/services/ai-quality.service.ts` ever opens a PDF, renders a page, invokes `pdftoppm`, or executes Tesseract.
